# SleepX-AI-Intelligent-Sleep-Analytics-Platform
SleepX AI is a data analytics dashboard built using Python, Pandas, NumPy, Streamlit, Matplotlib, and Seaborn. It helps analyze sleep quality, stress levels, wellness scores, lifestyle risks, and cognitive performance through interactive visualizations and advanced analytics.
Features
Interactive Streamlit Dashboard
Data Cleaning and Preprocessing
Feature Engineering using Pandas & NumPy
Sleep Efficiency Calculation
Lifestyle Risk Score Analysis
Wellness Score Calculation
Sleep Category Classification
Dynamic Sidebar Filters
KPI Cards for Key Metrics
Exploratory Data Analysis (EDA)
Correlation Heatmap
Pairplot Analysis
Stress vs Sleep Quality Analysis
Occupation-wise Sleep & Stress Insights
Dataset Preview Section
 Technologies Used
Python
Pandas
NumPy
Streamlit
Matplotlib
Seaborn
